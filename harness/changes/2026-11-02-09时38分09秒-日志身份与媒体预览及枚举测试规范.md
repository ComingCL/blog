## 修改内容摘要

访问日志与审计新增来源 IP 和登录用户名，后台支持筛选。修复 CSDN 图片外链加载、编辑双栏高度、文章操作按钮对齐和浅色按钮文字；复用现成 Markdown 编辑器，加入图片／视频柔和弹框预览。

后端和前端统一有限候选值的枚举定义；把先写反事实测试、观察失败、再实现及验证的工作范式写入 AGENTS 和 Harness，并接入前端组件测试。

## 修改内容详情

### 1. 请求身份与审计

- 访问日志带 `client_ip`、`user_id`、`username`、`visitor_id`、实际路径、方法、request ID、来源、状态码和耗时。请求统计应基于 `access_end`，`access_start` 只用于关联请求开始，避免重复计数。
- 审计保留原有 IP HMAC，新增 `client_ip` 和 `actor_username` 快照；API 输出 `username`。登录／注册成功请求结束日志能记录已确认身份；客户端不可自行声明 IP 或用户名。
- 后台增加用户名、IP 筛选与展示，继续限制管理员访问。历史未采集的字段显示缺失，不伪造回填。
- `002_audit_identity.sql` 在原有表上增加字段与索引；迁移按文件顺序幂等执行，仍只有六张表。重新生成 GORM Gen Query。
- 关联：`server/src/{middleware,audit,service,handler,models}/`、`server/src/infrastructure/db/{audit.go,connection.go,migrations,query}/`、`web/src/features/Admin.tsx`、`web/src/api/types.ts`。

### 2. 来源 IP 传递

- Web 启动入口改为 `web/server.mjs`：从 TCP socket 取得对端地址，在交给 Next.js 前覆盖未受信的 IP 头，并去掉客户端伪造的 SSR 内部标记。
- YAML 增加可选 `server.trusted_proxies`，默认空。仅受信上游代理可提供转发链；从右向左解析，停在最近的不受信节点。SSR 继续传递已验证的 IP、User-Agent 和会话。
- Go API 继续只绑定本机并只信任本机前端代理。Web 端口从现有 `server.origin` 读取，无新增应用环境变量。
- 关联：`web/{server.mjs,client-ip.mjs,server-config.mjs,package.json}`、`web/src/api/server.ts`、`server/src/{config,router}/`、配置示例和 README。

### 3. Markdown 写作与布局

- 比较 react-md-editor、ByteMD 后采用 `@uiw/react-md-editor@4.2.0`，复用中文工具栏、等高双栏、同步滚动、视图切换和全屏。
- 保留原有真实草稿、3 秒自动保存、版本冲突、独立预览和手动发布，新增上传并插入正文图片。
- 实测截图中的 CSDN 外链带来源页信息返回 403、不带返回 200；统一图片 no-referrer 策略，失败时显示明确提示与原图入口。
- 修复主操作链接文字继承成浅色的问题；编辑／预览／删除统一 34px 高度和对齐方式。桌面实测三者同一 y 坐标；编辑与预览面板实测均高 592px。
- 关联：`web/src/components/{MarkdownEditor,MarkdownImage,Content}.tsx`、`web/src/features/Admin.tsx`、`web/src/styles/editorial.css`。

### 4. 柔和媒体弹框

- `MediaPreview` 复用 Radix Dialog，提供模糊暗色遮罩、圆角面板、适配视口的图片／视频、关闭按钮和原文件入口。
- 图片点击放大；直接视频 URL 可用 `[标题](视频URL)` 或 `![标题](视频URL)`。视频仅打开后挂载播放器，关闭时明确暂停，支持 ESC 和焦点恢复。
- 不启用文章原始 HTML 或任意 iframe，图片放大继续使用 no-referrer。当前本地上传仍只支持 JPEG／PNG／WebP；视频使用 MP4／WebM 等直接媒体链接。
- 真实编辑器联调发现：内联 Markdown 图片渲染函数在父级更新时会导致弹框卸载。先加反事实测试，再把有状态的图片／链接渲染器稳定到模块级，修复实际点击后立即关闭的问题。
- 关联：`web/src/components/{MediaPreview,MarkdownImage,Content}.tsx`、媒体样式及 `MarkdownMedia.test.tsx`。

### 5. 枚举整理

- 新增 `server/src/models/enums/enums.go`：角色、文章／评论状态、点赞收藏、文章操作、评论筛选、分类查询、审计事件／类别／来源／结果／目标和响应码，均为具名类型＋类型化 const。
- Entity、DTO、VO、service 方法及 `common.Response.Code` 使用具名类型。`comment.go` 的管理员判断使用 `enums.RoleAdmin`，响应码使用 `enums.ResponseCode`，支持 IDE 跳转候选。
- 外部筛选参数校验未知候选；把文章“恢复操作”和“草稿状态”分开表达。数据库适配层显式转换 GORM Gen 字符串谓词，协议／数据库已有字符串值保持不变。
- React 统一使用 `web/src/models/enums.ts`；角色、状态、操作、认证模式、埋点和响应码的模型与业务判断不再散写候选字符串。自由文本、配置键和标准 HTTP 方法不误当业务枚举。
