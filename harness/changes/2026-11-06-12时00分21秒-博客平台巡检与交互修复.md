## 修改内容详情

### 1. 阅读和页面整理

- 首页首篇文章原来同时出现在“本期精选”和最新列表，且后台没有对应的精选配置；删除重复精选块。保留登录／注册深链接、个人记录、隐私说明、RSS 等有实际用途的页面。
- 目录改为按 Markdown AST 提取二级标题，支持格式化标题和 Setext 标题，不误读代码块中的 `##`；无标题时省略空目录，正文居中。
- 站点说明删除尚未实现的 30／180／7 天自动清理承诺，描述实际管理与按大小轮换机制。
- 关联文件：`web/src/app/page.tsx`、`web/src/app/posts/[slug]/page.tsx`、`web/src/components/headings.ts`、`web/src/app/about/page.tsx`。

### 2. 写作和后台布局

- 草稿创建失败可直接重试，保留单次挂载避免重复创建的保护。
- 未保存草稿点击站内链接时使用已有确认框；取消或保存失败留在编辑器，成功后跳转。已发布文章的草稿预览说明不影响已发布内容。
- 文章搜索提示涵盖草稿。手机管理表格改为卡片，日期不拆行，操作统一排列；删除与全局导航重复的侧栏返回入口。
- 站点设置说明改为用户能理解的内容，移除“配置保存在数据库”等实现文案。
- 关联文件：`web/src/features/Admin.tsx`、`web/src/styles/editorial.css`。

### 3. 列表、个人状态和认证恢复

- `web/src/api/usePage.ts` 收敛文章管理、评论和个人记录的列表生命周期：丢弃过期响应，失败可重试，最后一项移除后自动回到有效页。
- 点赞收藏绑定当前文章和账号，账号切换后忽略旧响应；状态载入前禁用修改，获取失败明确重试。
- 认证仅在明确 401 后清除用户；暂时性服务失败显示重新检查入口，旧请求不能覆盖较新的退出结果。服务端仍执行全部权限检查。
- 关联文件：`web/src/features/{Collections,Comments,Reactions}.tsx`、`web/src/components/{Providers,AppContext,Content}.tsx`。
- 核心设计影响：新增共享前端列表封装；未修改 API、六张表、事务、审计或 YAML 配置约定。

### 4. 回归工具和依赖维护

- 新增 `scripts/smoke_platform.mjs`，通过安装的 Chrome／Chromium 和 `playwright-core` 操作真实生产构建。仅接受回环高位 HTTP、项目名以 `-smoke` 结尾的隔离实例，读取私有配置但不输出凭据；测试数据和截图只留在忽略的运行目录。
- 脚本覆盖写作发布、注册留言、媒体预览、点赞收藏、权限、评论审核、账号和站名设置、手机／键盘／减少动态效果、留言删除、回收恢复和附属入口。API 检查遇到 429 按 `Retry-After` 等待一次；保留线上限流配置。
- 显式声明目录解析所用的 `unified`、`remark-parse`、`mdast-util-to-string` 依赖。YAML 从 2.8.1 更新到 2.8.3，修复深度嵌套导致栈溢出的依赖缺陷，依据 [上游安全公告](https://github.com/advisories/GHSA-48c2-rrv3-qjmp)。测试依赖 Vitest 更新到 4.1.12，并更新兼容范围内的 Vite、Undici；完整 npm audit 清零。
- 本机 npm 10 更新 Vitest 时发生 Arborist `edgesOut` 异常，改用与构建镜像一致的 npm 11.20.0 完成依赖更新；没有强制忽略 peer 依赖。
- 关联文件：`web/package.json`、`web/package-lock.json`、`web/server-config.test.mjs`、`docs/deployment.md`、`docs/frontend-redesign.md`、`harness/system-design.md`。

## 验证结果

### 反事实与 Red → Green

以下功能测试均先观察旧实现的目标行为失败，再修改生产代码：

- 首批前端测试（`npm run test:unit` 按 `reading`、`Reactions`、`Admin` 测试文件逐组运行）观察到 10 个目标失败：重复首篇、错误／空目录、退出后残留互动状态、未确认状态便可反向操作、失败无重试、创建失败无重试、站内链接绕过草稿保护、保存失败仍离开、已发布草稿的错误文案。
- 第二批 `Admin` 搜索、`Collections`、`Providers` 测试观察到 4 个目标失败：旧搜索覆盖新结果、取消最后一条收藏后留在空页、服务短暂故障清除身份、初次认证故障误提示重新登录。
- 第三批 `Providers` 测试观察到 1 个目标失败：较早的身份请求恢复已被较新请求确认退出的用户。
- `node --test server-config.test.mjs` 先观察深度 YAML 的断言失败：期望 `YAMLParseError`，实际为 `RangeError: Maximum call stack size exceeded`；更新依赖后通过。
- 最终前端单元／组件测试 10 个文件、36 个测试全部通过；配置／请求入口测试 8 个通过。
- 新增测试文件：`web/src/app/reading.test.tsx`、`web/src/features/{Admin,Reactions,Collections}.test.tsx`、`web/src/components/Providers.test.tsx`。浏览器脚本属于**补充回归测试**，不声称其全部流程均为本次新增功能或先测后写。
