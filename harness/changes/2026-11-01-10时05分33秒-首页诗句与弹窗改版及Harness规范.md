## 修改内容摘要

调研多个高 Star 开源前端项目后，调整首页、字体、登录窗口、确认弹框及操作提示。按用户最终要求，首页以小字号单行打字显示“行到水穷处，坐看云起时。”，不展示作者行；动态站名配置为 `Clarence Liu`，隐藏左下角 Next.js 开发工具入口。

## 修改内容详情

### 1. 开源调研与视觉主题

- 比较 shadcn/ui、Radix、Magic UI、React Bits、HeroUI、AFFiNE、Sonner 与霞鹜文楷。来源、调研时 Star 数、采用与取舍详见 `docs/frontend-redesign.md`。
- 新增炭黑／苔绿、米白、黄铜主题，统一卡片、输入框、按钮、后台与阅读排版。标题、诗句和正文采用本地霞鹜文楷，控件保留系统字体、代码保留等宽字体。
- 引入中文 Unicode 分片字体包，只使用 Regular，由本站提供字体资源，不请求外部字体 CDN。
- 关联文件：`web/package.json`、`web/package-lock.json`、`web/src/styles/editorial.css`、`web/src/app/layout.tsx`。

### 2. 首页诗句与站点名称

- `Typewriter` 实现单次逐字出现；预留全文尺寸，完成后光标淡出；后台标签页暂停，减少动态效果时直接显示全文。保留现有全屏视频、海报和背景暂停控制。
- 诗句最终为单行，桌面最大 44px，手机 20–27px；移除作者行。桌面实测 40.96px，320px 手机宽度实测 20px／单行高度 34px。
- 通过后台设置保存 `name: Clarence Liu`、`english_name: CLARENCE LIU`，实际持久化至现有站点配置并走原有审计；前后端默认值同步更新。名称与英文名相同时不重复显示第二行品牌文字。
- `next.config.mjs` 设置 `devIndicators: false`，关闭左下角开发工具指示器。
- 关联文件：`web/src/components/{Hero,Typewriter,Providers,AuthWindow}.tsx`、`web/src/api/types.ts`、`web/src/app/page.tsx`、`web/next.config.mjs`、`server/src/service/app.go`。
- 核心设计影响：没有新增表、接口或环境变量；站名继续由后台动态配置，诗句本身暂不提供后台配置。

### 3. 统一弹框与反馈

- `AuthWindow` 采用 Radix Dialog，桌面左右影像与表单分栏，手机上图下表单；登录／注册、密码可见切换、错误和处理中状态均连接真实接口。
- 抽出 `AppContext`，供窗口与共享表单读取站点／登录状态，避免 Provider 与账号功能相互依赖。独立登录和注册页面复用同一表单。
- 导航、权限提示、留言、点赞收藏的登录入口改为原地打开窗口，不离开当前文章，未提交留言继续保留。
- `ConfirmProvider` / `useConfirm()` 替换文章回收／永久删除、评论删除、草稿冲突重新载入的原生 confirm；使用明确影响说明、取消优先焦点、ESC 和焦点恢复。保留浏览器未保存草稿离开保护。
- Sonner 接入原有 `notify`，消息改在右下角显示，统一外观并使用中性反馈。
- 关联文件：`web/src/components/{AppContext,AuthWindow,ConfirmDialog,Providers}.tsx`、`web/src/features/{Account,Admin,Comments,Reactions}.tsx`。

### 4. Harness 与文档

- 根目录 `AGENTS.md` 作为 Agent 指引，约束架构、数据库事务、六表、路由、响应、审计、配置与 UI 复用。
- `harness/system-design.md` 总结系统当前设计；`harness/README.md` 定义阅读顺序、逐次记录和命名规则；`harness/templates/change.md` 提供统一模板。

- 更新 `README.md`、`docs/design.md` 至 v0.6，链接 Harness 和本次调研；截图保存到 `docs/assets/redesign/`。
